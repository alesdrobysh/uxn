# Uxn

This project is my attempt on writing [Uxn](https://permacomputing.net/Uxn/) emulator in C. 

Goals
- learn C and low-level programming
- learn more about Uxn
- don't forget how to write code manually like in pre-AI era
- have some fun

Non goals:
- get bored

All the code in `src` is carefully manufactured, every variable name is chosen with love.

Some tests in `tests` are auto-generated with LLM though :(
